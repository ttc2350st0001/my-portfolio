# Yuki Portfolio

就活用のWebポートフォリオです。

## 使用技術

- Next.js
- React
- TypeScript
- Tailwind CSS
- Lucide React

## 起動

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:3000` を開いてください。

## 公開前に変更する場所

`app/page.tsx` の以下を自分の情報へ変更してください。

- メールアドレス
- GitHub URL
- 制作物の公開URL
- 必要に応じてプロフィール文章

※制作実績の説明は就活用に作成した内容です。面接で説明できる範囲に合わせて調整してください。
